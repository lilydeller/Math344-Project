# Movie Recommendation System

Created for a USC MATH 344L project, where we applied linear algebra (matrices) in Google Colab to build a movie recommendation system.

Goal: We will represent movie ratings as a matrix, explore the MovieLens 100K dataset, and explain why a recommender system is a linear algebra problem. The missing entries of the matrix are precisely the ratings we want to predict.
